/////////// MATRIZ DE ADYACENCIA \\\\\\\\\\\\\\\

Hacer una matriz (vector de vectores) y registrar las "coordenadas" de las relaciones

Complejidad v^2 Ya que recorre dos veces los nodos

Para buscar si un nodo está conectado con otro, tenemos complejidad O(1)
Para buscar las conexiones de un nodo tenemos complejidad O(V)


/////////// Lista DE ADYACENCIA \\\\\\\\\\\\\\\
Hace una lista de las conexiones que tiene cada nodo
Su complijidad de espacio es O(V+E) ya que cada nodo registra a parte de él a las aristas
Su complejidad de consulta e iteración es O(deg(v)) ya que para ver si un nodo está conectado con otro o no debemos de checar su lista de conexiones (de longitud deg(v))



CÓDIGO

int n, m;
cin >> n >> m;

vector<vector<int>> grafo (n);
for(int i =0; i<n; i++){
    int u, v;
    cin >> u >> v;
    grafo[u].pushback(v); --v para cero indexado
    // grafo[v].pushback(u) para sistemas bidireccionales
}

/////////// BFS \\\\\\\\\\\\\\\
Se parte de un vértice conocido (puede ser cualquier vértice), consiste en dos fases que se repiten en cada vértice:
- Visita
- Exploración

***Visita:
    Consiste en registrar el vértice como ya visitado, sirve para poder saber si se puede llegar a un vértice o no
 
***Exploracion:
    Consiste en visitar a los grafos a los que se puede acceder desde el grafo actual, el orden en que se exploran los grafos no importan.
    En sí, es como el registrar los vértices a los que si se puede llegar para luego hacer una visita.

Para programar, se usa la estructura de datos QUEUE (cola) para almacenar los vértices visitados.
Para empezar, se registra el mismo grafo en el que se inicia.
Luego, se EXPLORAN los vértices "vecinos".
    El propósito es construir un árbol partiendo de un grafo, es como si acomodaramos en un arbol con copa en el vértice de inicio los vértices a los que si puede visitar.
Cada vértice que es VISITADO en la exploración se arregla a nuestra QUEUE (no importa el orden)
    Cuando ya no hay más vértices vecinos que los explorados se dice que nuestro vértice está completamente explorados
    Entonces ya está completada la iteración del vértice
    Cuando un vértice está explorado, se borra de la QUEUE (por eso es que se usan colas, para primer registro disponible y agregar hasta arriba)
Luego se selecciona el primer vértice que se guardó de los explorados, se EXPLORA ahora este vértice
    Este proceso es ITERATIVO y repetitivo, esto significa que se repite este proceso hasta 
    Cabe resaltar que si un vértice ya está visitado no se vuelve a marcar como visitado (no se arregla a la QUEUE)
